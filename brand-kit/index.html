05 · Mailchimp

Set it up in Mailchimp

Mailchimp doesn't take a brand kit as one file, so you enter it once and it fills every new email. It takes about five minutes.

  1. Open your brand settings. In Mailchimp go to Content (or Creative Assistant) → Brand kit.
  2. Upload the logo. Use kaffy-olaitan-logo-horizontal-burgundy.png.
  3. Add the colours. Paste these hex codes: #5C1729, #E2BF9C, #2E0A15, #8A3B4F, #F3E6E0, #FFFAF8.
  4. Pick the fonts. Headings: Montserrat. Body: Poppins. If one isn't in Mailchimp's font list, use Arial or Helvetica as the stand-in.
  5. Style the buttons. In the email builder set button colour #5C1729, text #F8ECE6, Montserrat bold, corner radius at the maximum.
  6. Save a template. Build one email with the header banner, then save it as a template so you never set this up again.

About the cursive font: email apps like Gmail don't load script fonts, so Great Vibes typed into Mailchimp will show up as plain text. Keep the cursive inside images (your logo and header banner already have it). For a cursive "Thank you" or sign-off, make it as a small image in Canva using Great Vibes.
